# Uddin Md. Borhan — Personal Academic Website

A static, responsive academic website designed for GitHub Pages.

## Deploy to GitHub Pages

1. Extract this ZIP.
2. Upload **all files inside this folder** to the root of your `umborhan/umborhan.github.io` repository.
3. Commit to the `main` branch.
4. GitHub Pages will update automatically.

## Replace the placeholders

- Profile photo: replace `assets/profile-placeholder.svg`.
- Research visual: replace `assets/research-placeholder.svg`.
- News images: replace `assets/news-placeholder.svg` or set a different image per card in `data.js`.
- Project visual: `assets/project-placeholder.svg` is included for future project cards.

Use the same filenames if you do not want to edit HTML/JS.

## Update publications and news

Edit `data.js`.

- `SITE_DATA.publications` controls the publication list and filters.
- `SITE_DATA.news` controls news cards.
- Use `featured: true` to show a paper in the default Featured filter.

## CV

The current DOCX CV is included at:

`assets/Uddin_Md_Borhan_Academic_CV.docx`

If you later create a PDF CV, add it under `assets/` and update the Download CV link in `index.html`.

## Academic profile links

The website includes links to:

A specific Google Scholar profile URL was not inserted because it was not independently verified during the website build.

## Privacy

The website intentionally omits National ID, passport number, date of birth, parents/spouse details, permanent residential address, and phone number.
